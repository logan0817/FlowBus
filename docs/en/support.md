# Support

[中文](../../SUPPORT.md) · [Documentation](README.md)

Use [GitHub Issues](https://github.com/logan0817/FlowBus/issues) for Android/core usage questions, bugs, feature requests, and documentation issues. Read the root and module guides, [compatibility guide](compatibility.md), and [troubleshooting](../../TROUBLESHOOTING.md) (Chinese) first. Prefer the latest released version, or explain why you cannot upgrade.

For a useful report, include:

1. The module and exact FlowBus version.
2. Android/JVM, device or emulator, JDK, Kotlin, Gradle, and AGP versions.
3. A minimal reproduction, ordered steps, expected behavior, and actual behavior.
4. Relevant stack traces and checks already attempted.
5. A minimal repository or code sample, with secrets and personal information removed.

Use the repository issue templates. Do not upload tokens, keys, phone numbers, email addresses, order IDs, or other private data in logs or screenshots. Complete, reproducible reports are easier to assess; maintainers may request missing information and can offer only limited help with unrelated application code.

Follow the [security policy](security.md) for suspected vulnerabilities. Report conduct or privacy concerns privately to `notwalnut@163.com`, following the [code of conduct](code-of-conduct.md).
